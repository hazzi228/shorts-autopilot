# Shorts Autopilot (облачная версия)

Работает на серверах GitHub бесплатно: ПК может быть выключен.

- 3 ролика в день: 10:00, 16:00, 22:00 по Москве (GitHub иногда запускает с опозданием до получаса).
- Когда сценариев остаётся меньше 6, бесплатный Gemini (секрет `GEMINI_API_KEY`) сам дописывает до 12 новых после выхода ролика. Если не получилось, попроси Claude «сделай новую пачку».
- Ролик и описание каждого запуска можно скачать 7 дней: вкладка **Actions** → запуск → **Artifacts** → `video`.
- Журнал: `log.txt`, вышедшие ролики: `state.json`, сценарии: `scenarios.json`.

## Настройка (один раз)

1. **Settings → Secrets and variables → Actions → New repository secret**
   Name: `YOUTUBE_TOKEN`, Secret: всё содержимое файла `token.json` из папки `shorts-autopilot` на рабочем столе
   (открыть Блокнотом, Ctrl+A, Ctrl+C, вставить).
2. Отключи автопилот на ПК, иначе ролики будут выходить дважды:
   Пуск → «Планировщик заданий» → «Shorts Autopilot» → Отключить.
3. Проверка: **Actions → Shorts Autopilot → Run workflow**. Через 3-5 минут ролик появится на канале.

## Полезное

- Выключить: **Actions → Shorts Autopilot → … → Disable workflow**.
- Дописать сценарии прямо сейчас: **Run workflow** с галочкой «Дописать новые сценарии».
- Если запуск упал, GitHub пришлёт письмо, а в `log.txt` будет причина.
- Если YouTube пишет `invalid_grant`, вход устарел: на ПК удали `token.json`, запусти `setup.bat`,
  потом обнови секрет `YOUTUBE_TOKEN` новым содержимым `token.json`.
