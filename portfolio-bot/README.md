# Бот-портфолио 24/7 (Cloudflare Workers)

Бот работает на серверах Cloudflare круглосуточно и бесплатно: ПК может быть выключен.
Бесплатного тарифа хватает с запасом (100 000 сообщений в день).

## Что умеет

- Портфолио, выполненные заказы с отзывами, «Обо мне», контакты.
- Кнопка **📝 Заказать бота или сайт**: клиент описывает задачу, и заявка приходит тебе в этого же бота.
  Любые другие сообщения клиентов (текст, фото, файлы) бот тоже пересылает тебе.
- Чтобы ответить клиенту, нажми на его сообщение → **Ответить** и напиши текст.
  Бот отправит ответ от своего имени, поэтому спам-блок твоего аккаунта переписке не мешает.

## Настройка (один раз, минут 10)

1. Зарегистрируйся на [dash.cloudflare.com](https://dash.cloudflare.com/sign-up) (только почта, карта не нужна).
2. Слева открой **Workers & Pages** один раз: Cloudflare создаст тебе адрес вида `имя.workers.dev`.
3. **ID аккаунта:** на той же странице справа есть **Account ID**, скопируй его.
4. **Токен:** справа вверху значок профиля → **Profile → API Tokens → Create Token** →
   шаблон **Edit Cloudflare Workers** → **Use template** → внизу **Continue to summary → Create Token**. Скопируй токен.
5. В GitHub: **Settings → Secrets and variables → Actions → New repository secret**, три секрета:
   - `CLOUDFLARE_API_TOKEN` — токен из шага 4;
   - `CLOUDFLARE_ACCOUNT_ID` — ID из шага 3;
   - `PORTFOLIO_BOT_TOKEN` — токен бота-портфолио (строка после `BOT_TOKEN=` в файле `.env` в папке `telegram-bot` на рабочем столе).
6. **Actions → Бот-портфолио → Run workflow**. Через минуту бот заработает в облаке.
7. Закрой окно бота на ПК: теперь он не нужен, а два бота с одним токеном мешают друг другу.
8. Открой бота в Telegram со своего аккаунта и нажми **/start**: он ответит «Ты владелец бота».

## Как менять тексты, работы и отзывы

Открой `portfolio-bot/data.json` в GitHub → значок карандаша → поправь → **Commit changes**.
Через минуту бот сам обновится. Картинки кладутся в `portfolio-bot/images`, а их имя указывается в поле `image`.
Если в `data.json` ошибка (пропущена запятая или кавычка), GitHub пришлёт письмо, а бот продолжит работать со старой версией.

Владельца бот узнаёт по нику из `data.json` (`owner.telegram`). Если сменишь ник в Telegram, поменяй его и там.
