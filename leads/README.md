# Поиск клиентов на ботов и сайты

Каждый час с 8:00 до 23:00 по Москве GitHub бесплатно просматривает открытые ленты заказов
(публичные Telegram-каналы, куда заказы выкладывают сами заказчики), отбирает свежие заявки, где
человеку нужен Telegram-бот или сайт, и присылает их тебе в Telegram:

- текст заявки, откуда она и когда опубликована;
- ссылку на заявку и контакт автора, если он его указал;
- готовый черновик отклика (нажми на него, и он скопируется).

Пишешь заказчику ты сам: инструмент никому ничего не отправляет, кроме тебя.
Так не будет спама и бана аккаунта.

## Настройка (один раз, 3 минуты)

1. В Telegram открой @BotFather → `/newbot` → придумай имя, например `Hazzer заявки`
   и юзернейм вроде `hazzer_leads_bot`. Скопируй токен, который он пришлёт.
   Отдельный бот нужен, чтобы не мешать боту-портфолио.
2. Открой нового бота и нажми **Start** (иначе он не сможет тебе писать).
3. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**,
   Name: `LEADS_BOT_TOKEN`, Secret: токен из шага 1.
4. Проверка: **Actions → Поиск клиентов → Run workflow**. Через минуту в боте появятся заявки
   за последние сутки.

Заявки с FL.ru и Kwork помечены «отклик на сайте биржи»: отвечать нужно там, Telegram не нужен.
Для Kwork нужен аккаунт продавца (бесплатно, kwork.ru).

## Несколько получателей

Чтобы заявки приходили ещё на один аккаунт, впиши в `leads/sources.json` ники всех получателей,
включая свой: `"owners": ["Hazzi71", "второй_ник"]`. Потом с нового аккаунта открой бота для заявок
и нажми Start. В течение часа он подключится и получит приветствие.

## Настройка под себя

- Каналы подобраны вручную (проверка 2026-11-20): только те, где заказ публикует сам заказчик
  или админ по его заявке. Каналы-агрегаторы, которые роботом перепечатывают заказы с Kwork, FL.ru
  и чужих чатов, убраны, а такие посты дополнительно отсекаются фильтром `AGGREGATOR` в `finder.py`.
  RSS FL.ru и Kwork выключены (`rss_paused`, `kwork_paused`); чтобы вернуть, перенеси их в `rss` / `kwork`.
- `leads/sources.json`: список каналов (`telegram`, имя после t.me/) RSS-лент и разделов Kwork (`kwork`: 37 создание сайтов, 38 доработка, 79 вёрстка, 41 скрипты и боты).
  Добавь канал, где часто бывают заказы, и он начнёт проверяться.
- Слова, по которым отбираются заявки, и черновик отклика: в начале `leads/finder.py`.
- Журнал запусков: `leads/log.txt`. Если какой-то источник перестал открываться, там будет написано.
- Выключить: **Actions → Поиск клиентов → … → Disable workflow**.
